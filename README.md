# lsproc

Linux의 `/proc` 파일시스템에서 프로세스와 시스템 정보를 읽어 출력하는 C 명령줄 프로그램입니다. 실행 파일 이름은 `ssu_lsproc`입니다.

## 실행 환경

- Linux 및 접근 가능한 `/proc` 파일시스템
- GCC, GNU Make, C 표준 라이브러리 개발 헤더
- `cat`, `tr`, `grep` 명령과 POSIX 셸: 환경변수·커널 버전 조회에 사용

다른 사용자의 프로세스 정보와 일부 시스템 정보는 권한이나 컨테이너 설정에 따라 조회가 제한될 수 있습니다.

## 빌드와 시작

```sh
git clone https://github.com/JJH07/lsproc.git
cd lsproc
make
./ssu_lsproc -t -n
```

`make`는 실행 파일 `ssu_lsproc`와 오브젝트 파일 3개를 생성합니다. 소스 또는 헤더를 수정한 뒤에는 다시 `make`를 실행합니다.

옵션 없이 실행하면 시작·종료 메시지만 출력합니다.

## 옵션

각 옵션은 `-t -n`처럼 따로 입력합니다. 아래에서 대괄호는 생략 가능함을 나타내며, 실제 명령에는 입력하지 않습니다.

| 옵션 | 기능 |
| --- | --- |
| `-f [PID ...]` | 열린 파일 디스크립터와 연결된 경로 조회 |
| `-t [PID ...]` | 프로세스 상태 파일의 앞 9개 행 조회 |
| `-c [PID ...]` | 실행 명령과 인자 조회 |
| `-n [PID ...]` | 프로세스 I/O 통계 조회 |
| `-m [PID ...]` | 프로세스 환경변수 조회 |
| `-k PATTERN ...` | `-m` 결과를 grep 기본 정규식으로 검색 |
| `-w` | 인터럽트 파일의 CPU 수와 숫자로 시작하지 않는 항목의 CPU당 평균 카운터 조회 |
| `-e` | `/proc/filesystems`에서 `nodev` 항목을 제외한 파일시스템 목록 조회 |
| `-l` | 시스템 가동 시간과 누적 CPU 유휴 시간 조회 |
| `-v` | 커널 버전 조회 |
| `-r` | 각 PID 목록의 앞 16개를 숫자 오름차순으로, 검색어 목록의 앞 16개를 문자열 순서로 정렬 |
| `-s ATTRIBUTE ...` | 현재 사용자 UID에 속하는 프로세스들의 지정 속성 조회 |
| `-o FILE` | 표준 출력을 파일에 기록. 기존 파일이 있으면 덮어씀 |

PID를 받는 옵션은 각각 최대 16개를 조회하며, 초과한 인자에는 안내 메시지를 출력합니다. PID를 생략하면 해당 옵션을 실행하는 자식 프로세스 자신을 조회합니다.

`-s`의 속성은 `FILEDES`, `STAT`, `CMDLINE`, `IO`, `ENVIRON`입니다. 여러 속성을 함께 지정할 수 있습니다.

## 사용 예시

현재 셸의 상태와 실행 인자를 조회합니다. `$$`는 셸이 자신의 PID로 치환합니다.

```sh
./ssu_lsproc -t $$ -c $$
```

커널 버전과 시스템 가동 시간을 조회합니다.

```sh
./ssu_lsproc -v -l
```

환경변수 중 `PATH` 항목을 검색합니다.

```sh
./ssu_lsproc -m -k '^PATH='
```

현재 사용자의 프로세스 상태와 I/O 정보를 조회합니다.

```sh
./ssu_lsproc -s STAT IO
```

조회 결과를 새로 지정한 파일에 기록합니다.

```sh
./ssu_lsproc -e -v -o result.txt
```

## 동작과 코드 구성

여러 옵션을 지정하면 입력 순서와 관계없이 `-f`, `-t`, `-c`, `-n`, `-m`, `-w`, `-e`, `-l`, `-v`, `-s` 순서로 조회합니다. 부모 프로세스는 옵션별 자식 프로세스를 생성하고 종료를 기다린 뒤 다음 옵션을 실행합니다.

| 파일 | 역할 |
| --- | --- |
| `main.c` | 옵션 파싱, 인자 정렬, 옵션 메모리 해제 |
| `ssu_lsproc.c` | 옵션 실행, 자식 프로세스 생성·대기, 출력 리다이렉션 |
| `func.c` | 프로세스·시스템 정보 조회와 출력 |
| `myheader.h` | 자료구조, 상수, 함수 선언 |
| `makefile` | 컴파일과 링크, 헤더 의존성 관리 |

## 현재 제한

- 일부 오류 상황에서도 종료 코드가 `0`입니다. 종료 코드만으로 조회 성공을 판단하지 말고 출력 메시지도 확인해야 합니다.
- 여러 PID를 조회할 때 일부 옵션의 헤더는 실제 조회 항목과 달리 `/fd`로 표시됩니다.
- 옵션 파서는 두 번째 문자로 옵션을 판별하므로 `at` 같은 잘못된 입력도 옵션으로 해석할 수 있습니다. 표에 명시한 형식을 사용하세요.
- `/proc` 정보는 실행 중 변합니다. 조회 도중 프로세스가 종료되거나 파일 디스크립터가 닫힐 수 있습니다.
